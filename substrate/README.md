# Flightdeck Epistemic Causal Substrate (ECS)

Deterministic, write-side governed bitemporal causal memory layer.

## Quickstart

```bash
# Run tests
uv run pytest

# Check memory status
uv run ecs status

# Retrieve memory for a file
uv run ecs check Sources/Flightdeck/DevCleaner.swift

# Run MCP stdio server
uv run ecs serve
```
